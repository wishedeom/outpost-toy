# Outpost
Standalone buildless canvas raycaster. Serve this directory with any static server. WASD move, arrow keys turn, Space/click shoots, R restarts. The enemy takes three hits, but killing it is optional. Reach the green exit on the far east wall to win. No external assets or dependencies.

Play: https://wishedeom.github.io/outpost-toy/

GitHub Pages publishes the root of the main branch automatically after a push.
